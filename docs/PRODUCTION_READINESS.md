# Production Readiness Checklist

## System Reliability

- Webhook endpoints tested
- API responses validated
- Retry logic defined
- Error handling documented
- Logging enabled

## AI Behavior

- Prompt tested
- Guardrails defined
- Tool-use rules enforced
- Fallback behavior documented
- Escalation paths created

## Data & Compliance

- Consent events logged
- Customer actions recorded
- Audit trails created
- Sensitive data protected
- Access controls reviewed

## Operations

- Slack alerts configured
- Failure notifications defined
- Monitoring in place
- Manual review process documented
- Deployment checklist completed
